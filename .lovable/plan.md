# Novaryn Android floating quick-note

Build Novaryn as a Capacitor Android app and add a native floating quick-note bubble that users can explicitly enable over other apps.

## User experience
- Add an Android-only setting to enable or stop the bubble. Explain the Android “Display over other apps” permission and request it only after the user chooses to enable the feature.
- Show a draggable native bubble while the user switches apps; tapping it opens a compact editor, with clear save and close actions.
- Keep the existing browser desktop picture-in-picture flow intact and provide an in-app fallback when Android permission is declined or unavailable.
- Do not claim a native quick-note edit is saved until the existing Novaryn note store confirms it; define the unavailable-app state as opening Novaryn before editing/saving.

## Implementation
- Add and configure Capacitor for Android with Novaryn’s existing app identity and Vite output.
- Implement a small Android Capacitor plugin/service for overlay permission checks, settings handoff, foreground notification, movable bubble, editor presentation, and explicit stop/revocation behavior.
- Bridge native save requests into the running WebView’s existing WatermelonDB layer; do not create an independent, silently divergent note database.
- Add app UI controls and lifecycle handling without changing desktop overlay behavior.
- Keep Android platform files generated by Capacitor and add required manifest/service declarations and native project configuration.

## Verification and delivery
- Verify web preview behavior and project compilation where available.
- Android APK generation and device validation require Android SDK/build tools not currently installed in this workspace. Do not claim an APK is built; provide local build steps and required permission/device tests.

## Technical details
- Use Capacitor Android and a narrowly scoped custom native plugin rather than reusing the browser Document Picture-in-Picture API.
- Request `SYSTEM_ALERT_WINDOW` through Android’s special-access settings and check `Settings.canDrawOverlays()` after return.
- Run the persistent bubble as an explicitly started foreground service with a user-visible notification and stop path; Android vendor/background limits may still interrupt it.
- The app’s current note data is held by WatermelonDB using the web IndexedDB adapter. Native UI must ask the WebView to persist through the existing data layer and report success/failure.
